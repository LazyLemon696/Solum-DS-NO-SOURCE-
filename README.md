# Solum-DS-NO-SOURCE-
Release of Solum for Nintendo DS as a ROM, but without Source. I don't have a permission for Solum owner himself to post a literal source code of HIS game here. Using GitHub to share files, because sharing through Google Drive, Mega, Mediafire etc look sus xd

# How to Run?

## Using emulator

1. Downloadd any Nintendo DS emulator like MelonDS, DeSmuME etc
2. Open SolumDS.nds file
3. Enjoy

## Using real hardware

1. Make sure that your Nintendo DS is Jailbroken (for me, i use R4 SDHC RTS Lite (2025) Card for Nintendo DS Lite with Twilight Soft installed on), if you have Jailbreaking troubles, visit [this link](https://www.reddit.com/r/flashcarts/comments/1m2ygw1/suggesting_tier_list_of_ds_flashcard_and_explain/) to select your flashcart ([this link](https://nds.flashcarts.net/card/) with more user - friendly ui), and [here](https://github.com/DS-Homebrew/TwilightMenu/releases) to download Twilight menu++ with tutorials and stuff
2. Make "roms" folder on your flashcart (if you dont have one)
3. Drag SolumDS.nds file into that folder
4. Insert flashcard into your NDS
5. Select "Solum DS" tab
6. Enjoy

# Movement

## build mode

DPad - move
A - hover up
B - hover down
X - turbo mode (you move faster)
Y - playtest mode
L - drag side\corner\center
R - move camera (hold R and press DPad keys to move camera)
SELECT - Block Select
START - Menu

## playtesting mode

DPad - walk
A - jump
B - Camera down
X - Camera up
Y - build mode
L - Camera left
R - Camera right
START - Menu

# Other things you need to know

* the max size of world is 64x64x64 blocks
* you can change the layout going to menu and selecting Layout: Beta\Classic
* The port size is 15x times lighter than original Solum 0.8.0
* The game saves in slm files, so it wont open original Solum map files (yet)
* In the main menu you can see debug info by pressing select
* Model limit in each world is 7 and their size can be 10x10x10 cubes
